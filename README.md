# KOF 6 键映射工具

## 功能
1. 在 `WASD` 的基础上增加两个组合方向键：`Q = A + S`，`E = D + S`。
2. `Right Arrow` 作为全局启停热键，按一下启用，再按一下禁用。
3. `Pause` 作为显示或隐藏窗口的热键。
4. 托盘图标双击也可以显示或隐藏窗口。

## 实现说明
1. 使用 Win32 全局低级键盘钩子监听按键，不依赖第三方 NuGet 包。
2. 使用 `SendInput` 发送真实的按下和松开事件，支持长按和组合键。
3. 项目代码兼容 `.NET Framework 4.x` 编译器，更适合在多个 Windows 版本上直接运行。

## 构建
1. 在项目目录执行：
   ```powershell
   .\build.ps1
   ```
2. 生成的可执行文件位于 `dist\kof6key.exe`。
